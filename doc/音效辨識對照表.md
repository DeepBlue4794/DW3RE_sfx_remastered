# 音效辨識對照表

請直接編輯本檔；之後告訴我已更新哪些列，我會讀取內容製作下一版。修改本表不會自動改動遊戲或重新建置 MOD。

- 以 Sys 編號為主，填入原版「檔名尾碼」、用途、狀態與備註。
- 不確定的對應請標「推測」；原版編號可以填多個候選，例如 `12 / 13`。
- 狀態可填：待辨識、推測、已試聽辨識、已遊戲確認、不替換。
- 「希望調整 dB」相對目前版本填寫；空白代表不額外調整。請同時描述太大／太小聲，避免只填模糊的倍率。
- 重製版試聽是未修改的基準音效；v0.2成品另有試聽連結。
- 先處理 Sys 音庫。若某種事件在這53項都找不到，可能需要檢查其他音庫。

## 後續音量預設（v0.4 起）

依使用者要求，所有後續替換預設相對 v0.3 增加 5 dB，並加峰值限制避免削波。實際 RMS 增幅依音效而異。每次從原始 WAV 重建，不累加前版增益；表格 dB 空白沿用此預設。現有五組對應不變。


## 2026-11-01：v0.5 音量預設（取代 v0.4 規則）

使用者回報仍太小聲，五個音效改為相對 v0.3 的 +10 dB 輸入增益及平滑飽和處理；解碼後 RMS 相對 v0.4 約增加 4–5 dB，音色可能稍硬。後續沿用 audio_settings.json、audio_processing.py、adpcm_encoder_safe.py，參考 build_v05.py，每次從原始 WAV 重建，不累加前版增益。表格 dB 空白沿用此預設。其餘 48 個音效不變。v0.5 尚待遊戲實測。
